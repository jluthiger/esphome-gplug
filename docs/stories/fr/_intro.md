# Manuel d'utilisation de METER

METER est un firmware libre pour les adaptateurs gPlug. Le gPlug lit l'interface client de votre
compteur intelligent et affiche la puissance, les index et l'historique dans une application qui
tourne sur l'appareil lui-même – dans le navigateur de votre téléphone ou de votre ordinateur, sans
cloud et sans compte.

Ce manuel est organisé par tâches. Chaque tâche commence par ce que vous voulez obtenir, vous guide
pas à pas à travers les écrans et se termine par la manière de vérifier que tout a fonctionné. Les
libellés comme {{S.next}} sont exactement les textes que vous voyez dans l'application.

Vous débutez ? Commencez par **Première mise en service**.
