Première mise en service

Connecter le gPlug au Wi-Fi

De quoi il s'agit

En tant que nouveau propriétaire d'un gPlug, je veux le connecter à mon Wi-Fi domestique afin de pouvoir ouvrir son application dans un navigateur.

Comment faire

  1. Branchez le gPlug sur l'interface client du compteur. Tant qu'il ne connaît aucun Wi-Fi, il ouvre son propre réseau nommé gPlug-Setup.
  2. Connectez votre téléphone à gPlug-Setup. Le téléphone ouvre la page de configuration de lui-même ; sinon, ouvrez http://192.168.4.1/ dans le navigateur.
  3. Touchez votre réseau domestique dans la liste et saisissez son mot de passe sous Paramètres Wi-Fi.
  4. Notez l'adresse sous Ensuite accessible sur le Wi-Fi domestique à – ou touchez Copier. Elle a la forme http://gplug-xxxxxx.local/.
  5. Touchez Enregistrer. Faites maintenant une capture d'écran : la page se ferme dès que le téléphone revient sur votre Wi-Fi domestique.
  6. Reconnectez le téléphone à votre Wi-Fi domestique et ouvrez l'adresse notée.

Comment savoir que cela a fonctionné

  • L'adresse notée affiche l'assistant de configuration du gPlug.
  • Le réseau gPlug-Setup disparaît peu après.

Remarques

  • La page de configuration suit la langue du téléphone.
  • Si l'adresse ne s'ouvre pas, cherchez le gPlug dans la liste des appareils de votre routeur sous son nom gplug-xxxxxx et ouvrez son adresse IP.

Vérifié avec le simulateur d'appareil le 30 septembre 2026. Vérifié sur du matériel réel : gPlugK 2026-09-16 (Android).

Lancer l'assistant et choisir l'appareil

De quoi il s'agit

En tant que propriétaire d'un gPlug fraîchement connecté, je veux indiquer quel modèle je possède afin qu'il communique correctement avec l'interface client de mon compteur.

Comment faire

  1. Ouvrez l'adresse du gPlug. La première fois, l'assistant s'ouvre sur Bienvenue. Il affiche la version du micrologiciel et le nom de l'appareil. Touchez Suivant.
  2. Sous Appareil, choisissez votre modèle, par exemple gPlugK. La désignation figure sur le boîtier.
  3. Affectation des broches (à modifier seulement si nécessaire) ne sert que si vous avez modifié le gPlug vous-même. Sinon, laissez les valeurs proposées.
  4. Touchez Suivant.

Comment savoir que cela a fonctionné

  • L'assistant passe à l'étape Smart Meter.
  • Le modèle choisi est enregistré, même si vous quittez l'assistant maintenant.

Vérifié avec le simulateur d'appareil le 30 septembre 2026.

Confirmer le profil du compteur et saisir la clé

De quoi il s'agit

En tant que propriétaire d'un gPlug, je veux choisir le bon profil de compteur et enregistrer la clé de mon gestionnaire de réseau afin que le gPlug puisse lire les valeurs de mon compteur.

Comment faire

  1. À l'étape Smart Meter, le gPlug écoute d'abord ce que votre compteur envoie. Après quelques secondes, la carte Détection du compteur affiche Compteur détecté et le protocole reconnu.
  2. Si un seul profil convient, il est déjà sélectionné. Si plusieurs conviennent, choisissez le profil de votre gestionnaire de réseau. Choisir un autre profil affiche d'autres profils.
  3. Si le compteur envoie des données chiffrées, saisissez la clé (GUEK) sous Clé (GUEK) : 32 caractères parmi 0–9 et A–F, comme dans la lettre de votre gestionnaire de réseau.
  4. Valeurs indique les valeurs que le profil lit.
  5. Touchez Suivant.

Comment savoir que cela a fonctionné

  • Suivant ne devient actif qu'une fois un profil choisi et la clé valide.
  • L'assistant passe à Fin et y vérifie la liaison avec le compteur.

Remarques

  • La clé est enregistrée uniquement sur le gPlug et n'est plus jamais affichée.
  • Si aucun signal n'arrive après une demi-minute, vérifiez le câble. Certains gestionnaires de réseau doivent d'abord activer l'interface client.

Vérifié avec le simulateur d'appareil le 30 septembre 2026. Vérifié sur du matériel réel : gPlugK 2026-09-14.

Comprendre le contrôle de la configuration

De quoi il s'agit

En tant que propriétaire d'un gPlug, je veux voir à la fin de la configuration si le compteur est vraiment lu, afin de corriger une erreur tant que je suis encore dans l'assistant.

Comment faire

  1. À l'étape Fin, la carte Liaison avec le compteur affiche d'abord En attente des premières données du compteur…. Selon le compteur, cela prend jusqu'à une minute.
  2. Dès que des données arrivent, Données reçues s'affiche avec le numéro du compteur, la puissance actuelle et le nombre de valeurs. Touchez Ouvrir la vue en direct.
  3. Si aucune donnée exploitable n'arrive, la carte Vérifier la configuration apparaît à la place, avec une explication et un bouton qui vous ramène directement à la bonne étape, par exemple Changer le profil du compteur. La signification de chaque message est expliquée au chapitre Quand quelque chose ne va pas.

Comment savoir que cela a fonctionné

  • Après Ouvrir la vue en direct, vous voyez la vue en direct avec Données à jour.
  • Après un bouton de la carte Vérifier la configuration, vous êtes à la bonne étape de l'assistant ; vos autres réglages sont conservés.

Vérifié avec le simulateur d'appareil le 30 septembre 2026.

Continuer alors que l'interface client n'est pas encore activée

De quoi il s'agit

En tant que propriétaire d'un gPlug dont le gestionnaire de réseau n'a pas encore activé l'interface client, je veux terminer quand même la configuration afin que le gPlug lise dès que le compteur envoie.

Comment faire

  1. À l'étape Fin, Aucun signal du compteur apparaît après une minute.
  2. Si vous êtes sûr que le modèle et le câble sont corrects, touchez Continuer quand même vers la vue en direct.

Comment savoir que cela a fonctionné

  • La vue en direct s'ouvre et affiche la même carte Vérifier la configuration jusqu'à l'arrivée de données.
  • Dès que le gestionnaire de réseau active l'interface, les valeurs apparaissent sans autre action.

Vérifié avec le simulateur d'appareil le 30 septembre 2026.
