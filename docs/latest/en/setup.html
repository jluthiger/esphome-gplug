First setup

Connect the gPlug to your Wi-Fi

What it is about

As the new owner of a gPlug I want to connect it to my home Wi-Fi so that I can open its app in a browser.

How to do it

  1. Plug the gPlug into the meter's customer interface. As long as it knows no Wi-Fi, it opens a network of its own called gPlug-Setup.
  2. Connect your phone to gPlug-Setup. The phone opens the setup page by itself; if it does not, open http://192.168.4.1/ in the browser.
  3. Tap your home network in the list and enter its password under Wi-Fi settings.
  4. Note the address under Afterwards reachable on your home Wi-Fi at – or tap Copy. It looks like http://gplug-xxxxxx.local/.
  5. Tap Save. Take a screenshot now: the page closes as soon as the phone switches back to your home Wi-Fi.
  6. Connect the phone to your home Wi-Fi again and open the address you noted.

How you know it worked

  • The address you noted shows the gPlug's setup assistant.
  • The gPlug-Setup network disappears shortly afterwards.

Notes

  • The setup page follows the phone's language.
  • If the address does not open, look for the gPlug in your router's device list under its name gplug-xxxxxx and open its IP address.

Checked with the device simulator on 30 September 2026. Checked on real hardware: gPlugK 2026-09-16 (Android).

Start the assistant and choose the device

What it is about

As the owner of a freshly connected gPlug I want to tell it which model I have so that it talks to my meter's customer interface correctly.

How to do it

  1. Open the gPlug's address. The first time, the assistant opens with Welcome. It shows the firmware version and the device's name. Tap Next.
  2. Under Device, choose your model, for example gPlugK. The model name is printed on the case.
  3. You only need Pin assignment (change only if needed) if you have modified the gPlug yourself. Otherwise leave the proposed values as they are.
  4. Tap Next.

How you know it worked

  • The assistant moves on to the Smart meter step.
  • The chosen model is saved, even if you leave the assistant now.

Confirm the meter profile and enter the key

What it is about

As the owner of a gPlug I want to choose the matching meter profile and store my grid operator's key so that the gPlug can read my meter's values.

How to do it

  1. In the Smart meter step the gPlug first listens to what your meter sends. After a few seconds the Detecting the meter card shows Meter detected and the protocol it recognised.
  2. If exactly one profile fits, it is already selected. If several fit, choose your grid operator's profile. Choose a different profile shows more profiles.
  3. If the meter sends encrypted data, enter the key (GUEK) under Key (GUEK): 32 characters from 0–9 and A–F, as in your grid operator's letter.
  4. Values lists the values the profile reads.
  5. Tap Next.

How you know it worked

  • Next only becomes active once a profile is chosen and the key is valid.
  • The assistant moves on to Done and checks the connection to the meter there.

Notes

  • The key is stored on the gPlug only and never shown again.
  • If there is still no signal after half a minute, check the cable. Some grid operators have to enable the customer interface first.

Understand the setup check

What it is about

As the owner of a gPlug I want to see at the end of the setup whether the meter is really being read, so that I can fix a mistake while I am still in the assistant.

How to do it

  1. In the Done step the Connection to the meter card first shows Waiting for the first data from the meter…. Depending on the meter this takes up to a minute.
  2. When data arrives, Data received appears with the meter number, the current power and the number of values. Tap Open live view.
  3. If no usable data arrives, the Check the setup card appears instead, with an explanation and a button that takes you straight back to the right step, such as Change meter profile. What each message means is explained in the chapter When something is wrong.

How you know it worked

  • After Open live view you see the live view with Data current.
  • After a button on the Check the setup card you are in the matching step of the assistant; your other entries are kept.

Continue although the customer interface is not enabled yet

What it is about

As the owner of a gPlug whose grid operator has not enabled the customer interface yet, I want to finish the setup anyway so that the gPlug starts reading as soon as the meter sends.

How to do it

  1. In the Done step, No signals from the meter appears after a minute.
  2. If you are sure that the model and the cable are right, tap Continue to the live view anyway.

How you know it worked

  • The live view opens and shows the same Check the setup card until data arrives.
  • As soon as the grid operator enables the interface, the values appear without anything else to do.
